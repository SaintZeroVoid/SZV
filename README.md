# TGP - The Generics Pharmacy

This is a fully developed, fully functional online pharmacy e-commerce website built with modern web technologies. It includes:

- Responsive frontend with Tailwind CSS, Google Fonts, and Font Awesome icons
- User authentication (register, login, logout)
- Product catalog with search, sorting, and filtering
- Shopping cart with add/remove items and purchase functionality
- Backend API with Express.js for products, users, and orders
- Secure JWT-based authentication
- Client-side validation, SEO optimization, accessibility features, and analytics integration

This project is designed to be a complete online store experience similar to popular e-commerce websites.
